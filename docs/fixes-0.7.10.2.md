4. **Rank up and demote animation** (a new shared piece in ui.js or a small new file, used from one place):
   - **Rank Up window.** A small centred window over the dimmed page (not full screen) with a title "Rank Up", the exercise name, and a big plate (about 120 px, `large`). The **old plate spins** around its vertical axis like a coin (perspective 3D rotation, about 2 to 3 turns, starting fast and slowing down, about 1.5 s). While it is edge-on (thin) the picture is **swapped for the new plate**, so the change is never visible as a jump. It lands with a small bounce, a shine sweep, and a **burst of small sparks in the new tier's colour**. If the **tier** changed (for example Gold to Platinum) the burst is bigger and the window glows in the new colour; Diamond gets a rainbow glint. Below the plate: the new rank name and the kg to the next rank as the same bar as in the bubble. One button **Nice**; tapping outside also closes; a light haptic (`Phone.haptic()`) on landing.
   - **Demote window.** Calm and supportive, never shaming: title "Rank Changed" (not "Demoted"), the plate spins **the other way, slower**, the colours dim a little while it spins, it swaps to the lower plate while edge-on, and lands with a soft thud (a tiny settle, no sparks, no burst). Text like "Your Bench rank is now Gold I. Train it to win it back." One button **Got It**.
   - **First rank.** An exercise that gets its first rank ("Bronze III") uses the Rank Up window, but the plate drops in from above instead of spinning from an old one.
   - Motion rules: transform and opacity only, one `requestAnimationFrame`-free CSS or Web Animations driver, 60 fps on iPhone, no layout reads while it plays; **Reduce Motion** = a plain cross-fade between the two plates with no spin and no sparks.
   - **When it appears:** (a) at the end of a workout, for each exercise whose rank changed during it (the rank before the workout against after), shown one after the other, at most 3, then "and N more" in the Workout Done window; (b) when the app opens, if a rank is lower than the one last seen (for example because of a long break), once. Store the last seen rank per exercise in the profile (`profile.rankSeen`) so each change is shown only once and survives reloads; never show an animation for a rank that is the same as last seen. Leaderboard and Highest Rank card update without an animation.
